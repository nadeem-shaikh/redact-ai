> Status: Draft. Resolves implementation gaps left open by the v0.1
> design specs (`ARCHITECTURE_v0.1.md`, `API_SPEC_v0.1.md`, etc.) so
> that an AI coding agent — or a new contributor — can implement the

>
> Companion: per-rule detector specifications live in

## 1. Scope

This document is **prescriptive**. It freezes the implementation
choices that the v0.1 design specs deliberately left technology- or
detail-agnostic. Anything not pinned here continues to follow the
design specs by reference.

Stable IDs in this document use the prefix `BS-x.y` and are
referenced from tests and PRs.

## 6. Policy Schema

A **policy** is a YAML document validated by `policy/schema.py`
(Pydantic). The shipped default lives at
`examples/default_policy.yaml` and is loaded by ID `default`.

### 6.1 Schema

```yaml
id: <string, kebab-case>            # e.g. "default", "strict-finance"
version: <semver string>            # e.g. "0.1.0"
description: <string, ≤140 chars>
posture: "strict" | "lenient"       # default: "strict"
redaction_style:
  kind: "block" | "blur" | "pixelate" | "label"
  # style-specific parameters (see §10)
verbose_report: false               # MUST default to false
detectors:
  - id: <rule-id>                   # e.g. "FI-001"
    enabled: true | false
    threshold: "low" | "medium" | "high"   # min confidence to act
    overrides: { <key>: <value>, ... }     # detector-specific
```

### 6.2 Validation rules

- `id` matches `^[a-z][a-z0-9-]{1,63}$`.
- Every `detectors[].id` MUST exist in the detector registry; unknown
  IDs cause `E_POLICY` at load time.
- A detector listed twice causes `E_POLICY`.
- `posture: "lenient"` raises the effective threshold of every
  detector by one step (`low` → `medium`, `medium` → `high`,
  `high` → `high`).

### 6.3 Resolution order

1. Explicit policy passed to the API call.
2. `--policy <name>` CLI flag (v0.2).
3. Built-in `default` (always available).

## 7. Canonical Data Model

Defined in `src/redact_ai/models/`. JSON serialisation via
Pydantic.

### 7.1 `Document`

```python
class Token(BaseModel):
    id: str               # f"t-{page_idx}-{block_idx}-{line_idx}-{tok_idx}"
    text: str
    bbox: BBox            # pixel coords, post-preprocessing
    confidence: float     # 0.0–1.0 (OCR engine native)

class Line(BaseModel):
    id: str
    bbox: BBox
    tokens: list[Token]
    reading_order: int

class Block(BaseModel):
    id: str
    bbox: BBox
    lines: list[Line]
    block_type: Literal["paragraph", "table_cell", "form_field", "other"]

class Page(BaseModel):
    index: int            # 0-based
    width: int            # pixels
    height: int
    blocks: list[Block]

class Document(BaseModel):
    pages: list[Page]     # v0.1 invariant: len(pages) == 1
    source_hash: str      # sha256 of normalised input bytes
```

### 7.2 `BBox`

```python
class BBox(BaseModel):
    x: int                # top-left
    y: int
    w: int
    h: int
```

All bbox coordinates are integer pixels of the **post-preprocessing**
image. The preprocessing transform is recorded so detectors can
project back to the input pixel grid (BS-7.3).

### 7.3 Coordinate-projection guarantee

The Ingestor records a 2×3 affine transform `T_in_to_norm`. The
Redactor inverts it to map findings back onto the **input** pixel
grid before drawing masks. Determinism test `DT-001` asserts the
round-trip matches.

### 7.4 Document-model serialisation

JSON only. `Document.model_dump_json(by_alias=False)`. Field names
are stable; renames bump the manifest schema version.

### 7.5 Locale

`en-US` is the only locale in v0.1. `Hints.lang = "eng"` is passed
to Tesseract.

## 8. HTTP API — Concrete Contract

All payloads are JSON unless otherwise noted. Endpoints live under
the loopback origin `http://127.0.0.1:<ephemeral-port>`.

### 8.1 `POST /redact`

Request — `multipart/form-data`:

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `image` | file | yes | One of `image/png`, `image/jpeg`, `image/webp`. Max 25 MB. |
| `policy_id` | string | no | Defaults to `"default"`. |
| `style` | string | no | One of `block` / `blur` / `pixelate` / `label`; overrides policy. |
| `verbose_report` | string | no | `"true"` to include `matched_text` in the manifest. |

Headers:

- `X-Redact-CSRF: <token>` — required (BS-11.2).
- `Accept: image/<format>` (default) **or** `Accept: application/json`.

Response (default, `Accept: image/<format>`):

- `200 OK`
- Body: redacted image bytes.
- Headers:
  - `Content-Type: image/<input-format>`
  - `X-Redaction-Manifest: <base64-url(JSON)>` — full manifest, base64url.
  - `X-Redaction-Manifest-Sha256: <hex>`
  - `X-Redaction-Stats: redactions=<n>;categories=<n>`

Response (`Accept: application/json`):

```json
{
  "image": {
    "mime_type": "image/png",
    "bytes_b64": "iVBORw0KGgo..."
  },
  "manifest": { ... see §9 ... },
  "warnings": [
    { "code": "W_LOW_CONFIDENCE_TOKEN", "message": "...", "source": "ocr" }
  ]
}
```

Error response (any failure):

```json
{
  "error": {
    "code": "E_INPUT_FORMAT",
    "message": "Unsupported MIME type: image/bmp",
    "hint": "Convert to PNG, JPEG, or WebP and retry."
  }
}
```

HTTP status mapping:

| Code | HTTP |
| --- | --- |
| `E_INPUT_FORMAT` | 415 |
| `E_POLICY` | 400 |
| `E_OCR` | 502 |
| `E_DETECTOR` | 502 (only when *all* detectors failed; otherwise 200 + warning) |
| `E_REDACTION` | 500 |
| `E_IO` | 500 |
| CSRF / origin failure | 403 |

### 8.2 `GET /policies`

```json
[
  { "id": "default", "version": "0.1.0",
    "description": "Baseline strict policy for v0.1." }
]
```

### 8.3 `GET /healthz`

```json
{ "status": "ok", "version": "0.1.0", "ocr_engine": "tesseract-5.3.4" }
```

### 8.4 `GET /` and `GET /static/...`

Serves the single-page UI from `server/static/`.

### 8.5 OpenAPI

FastAPI's auto-generated `/openapi.json` is the source of truth.
The schema MUST match this section; CI runs a contract test
(`tests/integration/test_openapi_contract.py`).

## 9. Manifest Schema

### 9.1 Pydantic model

```python
class FindingOut(BaseModel):
    id: str                       # f"f-{rule_id}-{idx}"
    rule_id: str                  # e.g. "FI-001"
    category: Literal["IDENTITY", "CONTACT", "FINANCIAL",
                      "HEALTH", "CREDENTIALS", "LOCATION", "CUSTOM"]
    bbox: BBox                    # input-pixel coordinates
    confidence: Literal["low", "medium", "high"]
    matched_text: str | None = None   # only when verbose_report=True

class Stats(BaseModel):
    redactions_total: int
    by_category: dict[str, int]

class Manifest(BaseModel):
    schema_version: Literal["1"] = "1"
    policy_id: str
    policy_version: str
    runtime_version: str
    ocr_engine: str               # "tesseract-5.3.4"
    input_hash: str               # sha256, hex
    output_hash: str              # sha256 of redacted image bytes, hex
    created_at: str               # ISO 8601 UTC, second precision
    stats: Stats
    findings: list[FindingOut]
    warnings: list[Warning] = []
```

### 9.2 Determinism

- `created_at` is excluded from "equivalent manifest" comparison
  (resolves the `TC` open question).
- `findings` are sorted by `(page_index, bbox.y, bbox.x, rule_id)`
  before serialisation.

### 9.3 Example

See [`examples/manifest_example.json`](../examples/manifest_example.json).

### 9.4 Verbose mode warning

When `verbose_report=true`, the response MUST include the warning
`W_VERBOSE_REPORT_ENABLED` so downstream tooling can refuse to log
the manifest.

### 9.5 Signing

Out of scope for v0.1. The manifest carries `output_hash` so a
downstream signer can attach a detached signature without a schema
change.

## 10. Redaction Styles — Concrete Algorithms

All styles operate on the **input** image (after coordinate
projection from §7.3). All styles guarantee FR-4.5: zero original
sensitive pixels survive in the masked region.

### 10.1 `block` (default)

- Fill the bbox with a solid colour.
- Default colour: `#000000`. Configurable via
  `redaction_style.color: "#RRGGBB"`.
- Padding: 2 px on each side (configurable `padding_px`, default 2).

### 10.2 `blur`

- **Reject blur for v0.1.** Blur on text is reversible by deconvolution
  and violates FR-4.5. The `blur` value is accepted in the schema
  but the redactor MUST emit `W_STYLE_DOWNGRADED_TO_BLOCK` and
  produce a `block` mask. Lifted in v0.2 only with a non-reversible
  pixelation underlay.

### 10.3 `pixelate`

- Replace the bbox region with a flat colour computed as the
  per-channel mean of the *pre-mask* region pixels, then overwrite.
  Implementation: replace pixels with the mean colour (single colour
  fill — no mosaic — to avoid leakage from low-block-size mosaics).
- Configurable `mean_radius_px` is **ignored**; v0.1 always uses a
  flat fill.

### 10.4 `label`

- Draw a solid block (as in §10.1), then overlay centered white text
  with the rule category, e.g. `[FINANCIAL]`.
- Font: bundled `DejaVuSans-Bold.ttf` (Pillow includes it).
- Font size: `min(bbox.h * 0.6, 24)` px; if the rendered label exceeds
  `bbox.w - 4`, render only `[<initials>]` (e.g. `[FIN]`).

### 10.5 Style validation

A style not in `{block, pixelate, label}` after the blur downgrade
causes `E_POLICY` at policy-load time.

## 11. Bounding-Box Merge (FR-3.5)

After all detectors run, findings are merged with the following
algorithm to satisfy FR-3.5:

```text
1. Sort findings by (category, bbox.y, bbox.x).
2. For each pair (a, b) with the same category:
     if iou(a.bbox, b.bbox) >= 0.30
        OR  bbox_distance(a, b) <= 8 px on the same text line:
            replace with union(a, b);
            confidence = max(a.confidence, b.confidence);
            rule_id    = a.rule_id if a is higher-confidence else b.rule_id;
            keep both rule_ids in `merged_from`.
3. Repeat until a fixed point.
```

The merge is implemented in `pipeline/merge.py` and unit-tested with
property tests (Hypothesis) for idempotence and order-independence.

## 12. Confidence Levels

### 12.1 Token confidence (OCR) → finding confidence

| OCR token confidence | Finding confidence floor |
| --- | --- |
| `≥ 0.85` | `high` |
| `0.60 – 0.849` | `medium` |
| `< 0.60` | `low` |

A finding's confidence is the minimum of:

- the floor derived from the lowest-confidence covered token, and
- the detector's own confidence (e.g. checksum-passing PAN → `high`).

### 12.2 Threshold semantics

A policy's `threshold: "medium"` means: drop any finding whose
final confidence is `low`. Strict posture (default) treats `low` as
"redact anyway" (resolved per ADR-009).

### 12.3 Coverage requirement

`pipeline/redact.py` MUST have 100% line and branch coverage. CI
fails otherwise.

## 14. Server Implementation Constraints

(Concrete realisations of `FR-9.x` and `SECURITY_v0.1.md` §4a.)

### 14.1 Bind & port

- Bind: `127.0.0.1` only. Hard-coded; no env override.
- Port: ephemeral. Selected by binding to port `0`, then read back.
- After bind, log `"redact-ai listening on http://127.0.0.1:<port>"`
  and open the browser via `webbrowser.open(url)`.

### 14.2 CSRF

- On `GET /` the server sets `Set-Cookie: rai_csrf=<token>;
  SameSite=Strict; HttpOnly; Path=/` and embeds the same token in a
  meta tag (`<meta name="rai-csrf" content="...">`) for the JS to
  read.
- The token is 32 random bytes, urlsafe-base64-encoded.
- The JS reads the meta tag and sends the token as
  `X-Redact-CSRF: <token>` on `POST /redact`. The server compares
  header against cookie using `secrets.compare_digest`. Mismatch →
  `403 / E_CSRF`.
- Token lifetime: process-lifetime; rotated on server restart.

### 14.3 Origin / Host enforcement (middleware)

```text
allowed_hosts = {"127.0.0.1", "127.0.0.1:<port>", "localhost",
                 f"localhost:<port>"}
```

- If `Host` not in `allowed_hosts` → `403 / E_ORIGIN`.
- If `Origin` is present and not in `allowed_hosts` (with scheme) →
  `403 / E_ORIGIN`.
- CORS is **not** enabled. No `Access-Control-Allow-Origin` is set.

### 14.4 Persistence

- No request bytes touch disk. Image is read into memory; redacted
  output is returned in the response.
- The server MUST set `tempfile.tempdir = None` and never call
  `NamedTemporaryFile` in the request path.

### 14.5 Logging

- JSON lines to stderr.
- Schema: `{ "ts": "<ISO>", "level": "...", "event": "<snake>",
  "request_id": "<uuid>", "stage": "ingest|ocr|detect|redact|http",
  "duration_ms": <int>, "fields": { ... } }`.
- NEVER log `matched_text`, `image_bytes`, or any field derived from
  user pixels. The logger is wrapped with a redaction filter that
  drops fields named `text`, `bytes`, `matched_text`, `b64`.
