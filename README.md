# 🔐 redact-ai

**Redact before you prompt.**

redact-ai is a privacy-first tool that detects and removes sensitive personal data (PII) from text, PDFs, and images before sending them to AI tools like ChatGPT or Claude.

---

## 🚨 Problem

People frequently paste sensitive information into AI tools:

- Medical reports  
- Financial statements  
- Government IDs  
- Personal contact details  

This creates risks:
- Data leakage  
- Unintentional exposure of private data  
- Compliance issues in professional settings  

There is currently no simple tool that sanitizes data before AI usage.
