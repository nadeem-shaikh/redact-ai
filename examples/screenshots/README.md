# screenshots/

Illustrative screenshots used in documentation, the project website,
and announcements.

These are **not** test fixtures — they exist to communicate what
`redact-ai` does to a human reader.

## Conventions

- Use clearly synthetic content. Treat every screenshot as if it will
  be reproduced in a public blog post.
- Pair "before" and "after" screenshots where it aids understanding:
  - `before-bank-statement.png`
  - `after-bank-statement.png`
