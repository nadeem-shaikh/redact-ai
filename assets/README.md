# assets/

Visual assets that support the project: diagrams, mockups, and
brand resources.

## Subdirectories

- [`diagrams/`](./diagrams) — Architecture and data-flow diagrams
  referenced from the docs.
- [`mockups/`](./mockups) — UX mockups for current and planned
  surfaces.
- [`logos/`](./logos) — Brand and logo assets for the project.

## Conventions

- Prefer source-of-truth formats: `.svg` for diagrams and logos,
  editable design files for mockups.
- Keep exported `.png`/`.jpg` versions alongside the source where
  helpful for documentation embedding.
- Keep filenames descriptive: `architecture-overview.svg`,
  `cli-flow-mockup-01.png`.
