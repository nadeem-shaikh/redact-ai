# mockups/

UX mockups for `redact-ai` surfaces: CLI output, desktop windows,
share-sheet integrations, and review screens.

## Recommended Mockups (v0.1)

- `cli-output.png` — sample CLI run with redaction summary.
- `review-screen.png` — review step described in
  [`UX_FLOW_v0.1.md`](../../docs/UX_FLOW_v0.1.md).
- `policy-picker.png` — policy selection UI.

## Conventions

- Keep the **source** design file alongside any exported images.
- Annotate mockups with callouts when they illustrate specific UX
  decisions.
- Avoid embedding sensitive-looking content; use synthetic copy.
