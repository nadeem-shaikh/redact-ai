# logos/

Logo and brand assets for `redact-ai`.

## Expected Assets

- `redact-ai-mark.svg` — primary mark.
- `redact-ai-wordmark.svg` — wordmark for documentation headers.
- `redact-ai-icon.png` — square icon for favicons and app stores.
- `redact-ai-social.png` — social card / Open Graph image.

## Conventions

- Provide a vector source (`.svg`) for every logo.
- Provide light-mode and dark-mode variants where applicable.
- Keep colour and typography choices documented in a future
  `BRAND.md`.
